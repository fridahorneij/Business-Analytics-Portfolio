# 📊 Automated Business Insight Pipeline (AI + SQL)

* **Project Goal**: Automate the detection of market patterns from unstructured SQL data for a Business Analytics portfolio.
* **The Tech Stack**: Python 3.14, SQLite, and Gemini 1.5 Flash API.
* **The Challenge**: During automation, the project hit a **429 Rate Limit error**.
* **The Solution**: I developed a **throttling script** and a manual update bypass to ensure the database was fully populated with insights despite API restrictions.
* **Results**: Successfully identified Miami Real Estate price-sensitivity, tech stock fundamentals, and marketing conversion friction points.
